## Conclusions

In this study, we have highlighted the problems of lower accuracy and bias of machine learning models for stroke prediction caused by unbalanced classes in the dataset. Experiments show that machine learning models trained on imbalanced data are biased towards the class with the best performing data. Consequently, we discovered high specificity but low sensitivity for the stroke detection problem because the stroke patient class was in the minority.
